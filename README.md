"# JavaScript-Image-Slider" 

A simple and responsive image slider built with HTML, CSS, Bootstrap, and JavaScript.

## Features

- Display images in a lightbox.
- Navigate to the next and previous images.
- Close the slider using the close button.
- Keyboard navigation:
  - Right Arrow → Next image
  - Left Arrow → Previous image
  - Escape → Close the slider
- Infinite image looping.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (DOM Manipulation)
